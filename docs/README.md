## 变更约定
- 新功能/需求评估:先看 ROADMAP 是否已有对应项(P0 立即 / P1–P3 排期),再决定"立即实现"或"入规划"。
- 已交付:在 AGENTS 会话状态与 DESIGN §14.1 同步更新(M 序号递增),专项细节入 TUI_OPTIMIZE 对应条目并标 ✅。
- 规划变化:更新 ROADMAP 状态列(✅/进行中/未动)。
