# 章节节奏自检

节奏问题不是「写得太长」,是**读者在同一状态里待太久**。判断标准很朴素:
连续几段,读者的处境和掌握的信息有没有变?

## 每段必须推动一件事

一段(通常 3–8 行)至少完成一项:

| 推动类型 | 说明 |
|---|---|
| **信息** | 读者知道了一件新的、改变判断的事 |
| **处境** | 角色的处境变好或变坏(位置、资源、时间、关系) |
| **决定** | 角色做了一个不可撤回的选择 |
| **危险** | 威胁更近了一步(时钟、追兵、暴露风险) |

**四样都没有的段落 = 水段**,要么删,要么合并到相邻段落。

## 连续三段不变就换挡

如果连续三段都没让处境或信息变化,读者已经在原地了。此时至少做一件事:

- 缩短:三段并成一段;
- 换视角:从另一个人的眼睛看同一件事(同一事实换视角 ≠ 重复,信息会变形);
- 推进:让某件事**发生**。

## 章节的三个位置

- **开头 10%**:给出本章的问题或变化,不要用纯场景铺垫开场(读者要的是
  「这一章会怎样」)。
- **中段**:必须有一次**不可逆**的事发生(决定、暴露、损失)。没有中段转折的
  章节会读成流水账。
- **结尾 10%**:留一个**具体**的未解决问题(不是「接下来会怎样」的感慨)。

## 场景的进出

- 进场景前问:这个场景**必须发生在这**吗?能不能在电话里、在路上解决?
- 场景结束时,至少有一个变量变了。
- 连续两个场景如果只是为了换地方,合成一个。

## 对话不是节奏

对话多不等于节奏快。**三轮以上没有信息交换的对话要压缩或删掉**
寒暄、复述已知信息、情绪宣泄重复。

## 逐章自检

1. 本章的问题是什么?一句话。
2. 中段的不可逆事件是什么?
3. 结尾留下的问题是什么?
4. 有没有连续三段没推动?(标出来,合并或删)
5. 本章字数是否可以从 20% 压到 12% 而不丢信息?

## 最小示例

草稿章节 4,5,600 字,读下来「很顺但记不住讲了什么」。

- 本章问题:沈砚要不要把证物交给新搭档。
- 连续三段不变:第 2–4 段都在「两人在车里沉默/看窗外」⇒ 三段并成一段,
  省 400 字。
- 中段转折:**有** —— 沈砚把证物交出去了(不可逆)。但转折出现在 78% 处
  (太晚,读者已经失去耐心)⇒ 前移:第 2 段就交,后面写后果。
- 结尾问题:新搭档打开证物袋时,发现多了一张不该存在的照片。✅ 具体,
  不是感慨。
- 可压 20%:整理后 4,700 字,信息量不变。

补一句:压完后仍慢的那段是「两人回忆往事」—— 它是**后面转折的解释**,
可以移到下一章开头当悬念,不要留在本章。
