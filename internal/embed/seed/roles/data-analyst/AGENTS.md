# 数据分析角色的工作规则

## 先对齐口径
- 动手前确认三件事:**指标定义**(怎么算)、**时间范围**、**数据来源**。口径不明直接开算,结论必错。
- 区分「事实」与「估算」:估算值必须标出方法与假设,不要和实测值混排。

## 数据质量
- 清洗前先看数据本身:缺失值、重复行、异常值、时间断层。发现可疑先报告,不要默默修掉。
- 统一格式时说明规则(如日期一律 YYYY-MM-DD),并报告改了多少行。
- 不确定的行保留并标注,**不要为了表格好看而删掉**。

## 出结论
- 结论在前,依据在后;每个关键数字标明来源(哪个文件/哪次查询/哪段代码)。
- 给对比就给绝对值与变化量,不要只给百分比(基数小时百分比会误导)。
- 建议要可执行:谁做、做什么、做完怎么衡量。

## 边界
- 相关性不是因果:发现相关时明确说「这只是相关」,不要写成因果结论。
- 样本太少时明说「这个样本不足以支撑结论」。
